# Квітко — автоматизована інформаційна система управління замовленнями

## Опис проєкту

**«Квітко»** — вебзастосунок для автоматизації процесу оформлення замовлень у квітковому магазині.

Система дозволяє користувачам переглядати асортимент квітів, формувати кошик покупок, реєструватися, авторизуватися та оформлювати замовлення. Інформація про товари, клієнтів і замовлення зберігається в базі даних MySQL.

Проєкт розроблено в межах курсової роботи на тему **«Проєктування АІС управління замовленнями у квітковому магазині “Квітко”»**.

## Мета проєкту

Метою проєкту є створення автоматизованої інформаційної системи, яка спрощує процес оформлення замовлень, забезпечує зберігання інформації про товари та клієнтів і підвищує зручність взаємодії користувачів із квітковим магазином.

## Функціональні можливості

- Перегляд каталогу квітів із фотографіями, назвами та цінами.
- Пошук і сортування товарів у каталозі.
- Додавання товарів до кошика.
- Зміна кількості товарів і видалення їх із кошика.
- Автоматичний розрахунок загальної вартості замовлення.
- Реєстрація нових користувачів.
- Авторизація користувачів за електронною поштою та паролем.
- Оформлення замовлень із заповненням контактних даних.
- Вибір способу отримання замовлення: доставка або самовивіз.
- Вибір способу оплати.
- Збереження замовлень у базі даних.
- Перегляд історії власних замовлень.

**Основні компоненти:**

- `Program.cs` — серверна частина, API, авторизація та обробка замовлень.
- `wwwroot/flowshop.html` — користувацький інтерфейс із HTML, CSS та JavaScript.
- `wwwroot/images/` — зображення квітів.
- `appsettings.json` — основні налаштування застосунку.
- `*.sql` — SQL-скрипти для створення структури бази даних.
- `.gitignore` — виключення службових файлів із Git.

## База даних

Для зберігання інформації використовується реляційна база даних **MySQL** під назвою `flower_shop`.

Основні таблиці:

- `Users` — облікові записи користувачів.
- `Customers` — контактна інформація клієнтів.
- `Products` — каталог товарів.
- `Orders` — інформація про замовлення.
- `OrderItems` — товари, що входять до замовлень.

## Встановлення та запуск

### 1. Необхідне програмне забезпечення

Для запуску проєкту потрібно встановити:

- .NET SDK 9.0
- MySQL Server
- MySQL Workbench (для зручної роботи з базою даних)
- Visual Studio Code або інше середовище розробки C#

### 2. Налаштування бази даних

Створити базу даних `flower_shop` та виконати SQL-скрипти проєкту для створення необхідних таблиць.

### 3. Налаштування підключення

Налаштувати рядок підключення `ConnectionStrings:MySqlConnection` через .NET User Secrets, використовуючи власні параметри MySQL Server.

Паролі та інші конфіденційні дані не повинні зберігатися у відкритому репозиторії.

### 4. Запуск вебзастосунку

Відкрити папку проєкту у Visual Studio Code та виконати в терміналі:

```bash
dotnet restore
dotnet run
```

Після запуску відкрити у браузері локальну адресу, вказану в терміналі.

## Практичне застосування

Вебзастосунок «Квітко» може використовуватися як основа для системи онлайн-замовлень невеликого квіткового магазину.

Він дозволяє покупцям самостійно вибирати товари, формувати замовлення та переглядати інформацію про здійснені покупки.

## Перспективи розвитку

У майбутньому планується:

- Розробити адміністративну панель для керування товарами та замовленнями.
- Додати можливість онлайн-оплати.
- Удосконалити відстеження статусів замовлень.
- Адаптувати систему для подальшого практичного використання.
- Розмістити вебзастосунок на віддаленому сервері.
