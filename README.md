# Квітко — автоматизована інформаційна система управління замовленнями

## Опис проєкту

**«Квітко»** — вебзастосунок для автоматизації процесу оформлення замовлень у квітковому магазині.

Система дозволяє користувачам переглядати асортимент квітів, формувати кошик покупок, реєструватися, авторизуватися та оформлювати замовлення. Інформація про товари, клієнтів і замовлення зберігається в базі даних MySQL.

## Мета проєкту

Метою проєкту є створення автоматизованої інформаційної системи, яка спрощує процес оформлення замовлень, забезпечує зберігання інформації про товари та клієнтів і підвищує зручність взаємодії користувачів із квітковим магазином.

## Функціональні можливості

- Перегляд каталогу квітів із фотографіями, назвами та цінами.
- Пошук і сортування товарів у каталозі.
- Додавання товарів до кошика.
- Зміна кількості товарів і видалення їх із кошика.
- Автоматичний розрахунок загальної вартості замовлення.
- Реєстрація нових користувачів.
- Авторизація користувачів за електронною поштою та паролем.
- Оформлення замовлень із заповненням контактних даних.
- Вибір способу отримання замовлення: доставка або самовивіз.
- Вибір способу оплати.
- Збереження замовлень у базі даних.
- Перегляд історії власних замовлень.
